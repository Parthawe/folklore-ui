# Folklore design

The user approved an editorial reference library. Preserve that direction over randomized alternatives. Readers use this alongside an editor, often on a laptop; support both dark and light rather than binding content to one lighting condition.

Source Sans 3 provides readable labels and prose. Code uses a system monospace stack. A solid blue field introduces search; a charcoal catalog holds specimen previews. Borders separate navigation and entries. Typography and real demonstrations carry identity. The Folklore mark is two offset open-book planes, rendered as geometric SVG.

The index is an Operate surface; entries are Read surfaces. The signature interaction is moving from a vague description to a named subpart highlighted inside a working specimen. Styles are allowed to express their own visual rules inside bounded specimens.
