# Minimalism

A deliberately reduced visual vocabulary that gives essential content and actions room to be understood.

Platform: style
Terminology: Established approach
Aliases: minimal design

## Descriptions people use

- almost nothing on the page
- lots of space few colors

## Defining signals

- **Limited element count** (Visual signal): Only a few content and control types compete for attention.
- **Generous negative space** (Visual signal): Unoccupied space separates the small number of elements.
- **Clear typographic hierarchy** (Visual signal): Type size and placement establish the reading order.

## Behavior

Remove competing decoration and secondary content before reducing affordances. Keep a small palette, readable type, and an obvious primary action.

## Build prompt

Create a minimalism visual direction for the current project. Remove competing decoration and secondary content before reducing affordances. Keep a small palette, readable type, and an obvious primary action. Preserve the existing task flow, content, accessible contrast, clear focus, and reduced-motion support.

## Debug prompt

Check hidden navigation, unlabeled icon controls, insufficient information, and empty space that separates related content.
