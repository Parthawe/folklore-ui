# Folklore design system

The current visual reference is [Paper](https://paper.design/). Folklore adopts its black outer canvas, warm ivory type, restrained graphite surfaces, and framed editor composition. Folklore keeps its own name, artwork, catalog and copy.

## Typography and color

Self-hosted DM Sans Variable approximates the reference’s light, open typography without distributing its commercial Matter font. The compact introduction uses weight 360 at 34px; specimen names use 29px. Supporting text is neutral gray. Dark mode defaults to black, graphite #282828, ivory #eeeee5, and restrained lavender selection accents. A neutral light theme remains available.

## Desktop editor

A 66px header and compact introduction precede one rounded editor window. Its title bar, full-width search, index, specimen canvas, and inspector form a connected workspace. The desktop index is 182px; the inspector is 258px. The live specimen height follows the viewport, between 245px and 420px, reserving room for the live readout. Search, the complete live canvas, and every anatomy control must fit without scrolling at 1280×720 and 1440×900.

At 980px the inspector moves beneath the specimen. At 700px the workspace stacks and the catalog becomes a horizontal rail. The shell uses fine neutral rules and 4–5px control corners; only the editor has a larger 12px radius.

## Specimen visuals and behavior

The live reference-library example has warm paper artboards, olive geometric cover studies, detailed navigation and a working native dialog on a plain graphite canvas. Its artwork is code-native. Dim, blur and dismiss inspection update the real dialog layers. Other visual-style examples keep their own defining palettes.

Search, keyboard access, focus restoration, platform filters, local saves, copyable briefs, failure recovery, downloads, copyright and policy links remain functional. Respect reduced motion. Avoid promotional filler, decorative grids across the shell, oversized desktop headings, invented proof and unrelated reference branding.

## Refinement pass

Anatomy descriptions use 12px text and part names use 13px. Alternate descriptions live in a disclosure. The search Clear control and Escape preserve the current specimen; changing the query within the same result avoids reloading its iframe. Platform filtering selects a matching specimen when the current entry is excluded. Catalog selection stays within its own scrolling rail. The installation page uses padded neutral download controls and consistent code panels. Legacy primary-button overrides were removed so specimen controls follow the documented palette.
