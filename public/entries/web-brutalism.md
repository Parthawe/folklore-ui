# Web brutalism

A loose web label for exposed structure, direct typography, and an intentionally unpolished or uncompromising presentation.

Platform: style
Terminology: Contested label
Aliases: brutalist web, raw HTML look

## Descriptions people use

- raw html website
- plain ugly links browser default

## Defining signals

- **Exposed document structure** (Visual signal): Headings, rules, and links expose the document’s structure.
- **Direct typography** (Visual signal): The type makes little attempt to hide its browser-like character.
- **Minimal decorative finish** (Visual signal): Controls remain visually direct and minimally decorated.

## Behavior

Keep the document hierarchy visible and controls honest. Use deliberate typography and direct links without sacrificing responsive behavior or accessibility.

## Debug prompt
