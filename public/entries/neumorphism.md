# Neumorphism

Controls appear molded out of a shared soft surface, with paired light and dark shadows.

Platform: style
Terminology: Industry-coined trend
Aliases: soft UI

## Descriptions people use

- soft buttons pushed out of background
- embossed controls same color as page

## Defining signals

- **Continuous surface** (Visual signal): The background and controls share the same base tone.
- **Paired soft shadows** (Visual signal): Light and dark shadows make the dial appear raised.
- **Inset pressed states** (Visual signal): A pressed control appears recessed into the surface.

## Behavior

Use a shared surface tone and coherent directional shadows. Give controls visible boundaries and high-contrast labels instead of relying on subtle shadows alone.

## Build prompt

Create a neumorphism visual direction for the current project. Use a shared surface tone and coherent directional shadows. Give controls visible boundaries and high-contrast labels instead of relying on subtle shadows alone. Preserve the existing task flow, content, accessible contrast, clear focus, and reduced-motion support.

## Debug prompt

Check low contrast, selected states conveyed only by an inset shadow, and excessive blur removing all control boundaries.
