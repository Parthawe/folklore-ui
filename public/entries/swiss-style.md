# Swiss Style

A graphic-design tradition associated with systematic grids, asymmetric composition, sans-serif type, and clear information hierarchy.

Platform: style
Terminology: Historical movement
Aliases: International Typographic Style, Swiss typography

## Behavior

Build an explicit grid and type hierarchy. Use asymmetric placement with consistent alignment, restrained color, and enough space for reading.
