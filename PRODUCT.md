# Folklore

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Astro, TypeScript, native CSS; static output. Approved in the implementation plan.

## Users
Designers and developers who can describe an interface or visual style but need its terminology and implementation vocabulary.

## Product Purpose
Translate descriptions into named patterns, working demonstrations, anatomy, source references, and useful build or debug prompts.

## Operating Context
Browse the public website or install the offline Codex skill/plugin. One catalog supplies both. No model API, accounts, telemetry, or hosted search service in v1.

## Capabilities and Constraints
Thirty elements across web and macOS, ten styles, text search, comparisons, local bookmarks, Markdown export, offline lookup scripts. Browser macOS specimens are simulations. Source and site are public. MIT license for original work.

## Brand Commitments
Folklore is the product name. Original identity and content; Name That UI supplies the reference workflow. The approved direction is an editorial reference library, charcoal and light neutrals, blue accents, Source Sans 3, and code-specific monospace.

## Evidence on Hand
The approved plan and live reference workflow. API claims require primary documentation. No customer claims, endorsements, or usage metrics.

## Product Principles
- Show the mechanism before asking the reader to trust a name.
- Preserve platform and framework distinctions.
- Share content between browser and agent outputs.
- Keep installation usable without a service or API key.
