# Swiss Style

A graphic-design tradition associated with systematic grids, asymmetric composition, sans-serif type, and clear information hierarchy.

Platform: style
Terminology: Historical movement
Aliases: International Typographic Style, Swiss typography

## Descriptions people use

- grid clean sans serif red black poster
- asymmetric type strong alignment

## Defining signals

- **Systematic grid** (Visual signal): Consistent alignment relates the text and graphic elements.
- **Asymmetric balance** (Visual signal): Unequal visual weights balance across the composition.
- **Sans-serif hierarchy** (Visual signal): Sans-serif size and weight establish a direct reading order.
- **Purposeful alignment** (Visual signal): The lower rule and text share a deliberate alignment.

## Behavior

Build an explicit grid and type hierarchy. Use asymmetric placement with consistent alignment, restrained color, and enough space for reading.
