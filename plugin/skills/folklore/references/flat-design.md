# Flat design

An interface drawn with planar color and simple shapes, without pretending controls are physical objects.

Platform: style
Terminology: Established approach
Aliases: flat UI

## Descriptions people use

- solid colors no shadows
- simple colored blocks and icons

## Defining signals

- **Planar fills** (Visual signal): Color fills stay planar rather than imitating a material.
- **Simple shapes** (Visual signal): Basic geometric forms carry the illustration.
- **Little simulated material** (Visual signal): The button is recognizable without simulated lighting.

## Behavior

Use solid fills and clear grouping. Make clickable controls recognizable through placement, shape, labeling, and focus states.

## Build prompt

Create a flat design visual direction for the current project. Use solid fills and clear grouping. Make clickable controls recognizable through placement, shape, labeling, and focus states. Preserve the existing task flow, content, accessible contrast, clear focus, and reduced-motion support.

## Debug prompt

Check controls blending into static text, weak boundaries, and color used as the only state cue.
